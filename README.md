

# 📚 RAG 시스템 - 설치 및 실행 가이드

## 🤔 RAG가 뭔가요?

**RAG (Retrieval-Augmented Generation)** = 검색 + AI 답변

```
일반 AI: "임상시험이 뭐야?" → AI가 기억에 의존해서 답변 (부정확할 수 있음)

RAG AI:  "임상시험이 뭐야?" → 문서에서 관련 내용 검색 → 그 내용 기반으로 답변 (정확함!)
```

이 프로그램은 PDF 문서를 AI가 검색할 수 있는 데이터베이스로 만들어줍니다.

## 🔧 설치 방법 (처음 1번만)

### 1단계: Python 설치 확인

터미널(명령 프롬프트)을 열고 입력:
```bash
python --version
```
`Python 3.9` 이상이면 OK! 없으면 [python.org](https://python.org)에서 설치하세요.

### 2단계: 프로젝트 폴더로 이동

```bash
cd 다운로드받은폴더경로/rag_project
```

### 3단계: 가상환경 만들기 (권장)

```bash
# 가상환경 생성
python -m venv venv

# 가상환경 활성화
# Windows:
venv\Scripts\activate

# Mac/Linux:
source venv/bin/activate
```

활성화되면 터미널에 `(venv)`가 표시됩니다.

### 4단계: 패키지 설치

```bash
pip install -r requirements.txt
```

⏱️ 처음 설치 시 5~10분 정도 걸릴 수 있습니다.

## ▶️ 실행 방법

### 1단계: PDF 파일 준비

`rag_system.py`와 같은 폴더에 PDF 파일을 넣으세요.

> 다른 PDF를 사용하려면 `rag_system.py`의 13번째 줄을 수정:
> ```python
> PDF_PATH = "내파일이름.pdf"
> ```

### 2단계: 프로그램 실행

```bash
python rag_system.py
```

### 3단계: 질문하기

```
❓ 질문: 임상시험의 단계는?
```

프로그램이 PDF에서 관련 내용을 찾아서 보여줍니다!

## ❓ 자주 묻는 질문

### Q: "ModuleNotFoundError" 에러가 나요
→ `pip install -r requirements.txt`를 다시 실행하세요.

### Q: 모델 다운로드가 너무 오래 걸려요
→ 처음 한 번만 다운로드됩니다 (약 500MB). 이후에는 캐시를 사용합니다.

### Q: 다른 PDF도 사용할 수 있나요?
→ 네! `rag_system.py` 맨 위의 `PDF_PATH`를 바꾸면 됩니다.

### Q: 여러 PDF를 한꺼번에 넣을 수 있나요?
→ 현재 버전은 1개 PDF만 지원합니다. 여러 개를 넣으려면 코드 수정이 필요합니다.

### Q: GPU가 없어도 되나요?
→ 네, CPU로도 작동합니다. 다만 벡터 변환이 조금 느릴 수 있습니다.

### Q: ChatGPT/Claude와 연동하려면?
→ 검색 결과를 복사해서 ChatGPT나 Claude에 붙여넣으면 됩니다.
   또는 OpenAI API를 연동하는 고급 버전을 만들 수 있습니다 (요청 시 제공).

## 🔧 설정 변경하기

`rag_system.py` 상단의 설정값을 수정할 수 있습니다:

| 설정 | 기본값 | 설명 |
|------|--------|------|
| `PDF_PATH` | "14__임상시험의_개요_주완석.pdf" | PDF 파일 경로 |
| `CHUNK_SIZE` | 500 | 청크 크기 (글자 수) |
| `CHUNK_OVERLAP` | 100 | 청크 겹침 (글자 수) |
| `TOP_K` | 3 | 검색 결과 수 |
| `DB_PATH` | "./chroma_db" | DB 저장 위치 |
