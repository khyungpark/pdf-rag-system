# RAG 시스템 구축 보고서

**프로젝트명**: PDF 문서 RAG (Retrieval-Augmented Generation) 시스템
**작성일**: 2026-02-02
**버전**: v3.0 (LLM 답변 생성 통합)
**GitHub**: https://github.com/khyungpark/pdf-rag-system

---

## 1. 프로젝트 개요

### 1.1 목적
PDF 문서를 AI가 검색할 수 있는 벡터 데이터베이스로 구축하여, 자연어 질문에 대해 관련 문서 내용을 검색하고 **Claude LLM이 자동으로 답변을 생성**하는 RAG 시스템 개발

### 1.2 주요 기능
| 기능 | 설명 | 구현 상태 |
|------|------|----------|
| PDF 텍스트 추출 | PyMuPDF를 이용한 텍스트 추출 | ✅ 완료 |
| 표(Table) 추출 | pdfplumber를 이용한 표 마크다운 변환 | ✅ 완료 |
| 이미지 설명 생성 | Claude Vision API로 이미지 내용 설명 | ✅ 완료 |
| 벡터 검색 | ChromaDB + Sentence-Transformers | ✅ 완료 |
| 웹 대시보드 | Streamlit 기반 UI | ✅ 완료 |
| 여러 PDF 지원 | 폴더 내 다중 PDF 처리 | ✅ 완료 |
| **LLM 답변 생성** | Claude API로 검색 결과 기반 답변 자동 생성 | ✅ 완료 (v3.0) |
| **자동 DB 구축** | 폴더 기반 일괄 처리 스크립트 | ✅ 완료 (v3.0) |
| **GitHub 연동** | 버전 관리 및 코드 공유 | ✅ 완료 (v3.0) |

### 2.4 Phase 4: LLM 답변 생성 통합 (v3.0) ⭐ NEW

**목표**: 검색 결과를 Claude API에 자동 전달하여 답변 생성

**생성 파일**: `llm_client.py`

```python
class RAGAnswerGenerator:
    def generate_answer(self, query, search_results):
        # 검색 결과 + 질문 → Claude API → 답변 생성
        ...
```

**프롬프트 설계**:
- 문서 기반 답변 우선
- 전문 지식(규제과학)으로 추론 보완
- 마지막에 전문가 상담 권고 문구 자동 추가

```
⚠️ 주의사항: 본 답변은 AI가 문서와 전문 지식을 바탕으로 생성한
참고 정보입니다. 정확한 규제 요건 확인 및 의사결정을 위해서는
식품의약품안전처 담당자 또는 해당 분야 전문가와 상담하시기 바랍니다.
```

### 2.5 Phase 5: 자동 DB 구축 스크립트 (v3.0) ⭐ NEW

**생성 파일**: `build_db.py`

**사용법**:
```bash

# 이미지 설명 포함 (API 키 필요)
python build_db.py --with-images

# 기존 DB에 추가 (삭제하지 않음)
python build_db.py --append
```

## 6. 사용된 기술 스택

| 분류 | 기술 | 버전 | 용도 |
|------|------|------|------|
| PDF 처리 | PyMuPDF | ≥1.24.0 | 텍스트/이미지 추출 |
| PDF 처리 | pdfplumber | ≥0.10.0 | 표 추출 |
| 벡터 DB | ChromaDB | ≥0.5.0 | 벡터 저장/검색 |
| 임베딩 | Sentence-Transformers | ≥3.0.0 | 텍스트 벡터화 |
| 웹 UI | Streamlit | ≥1.30.0 | 대시보드 |
| AI API | Anthropic | ≥0.30.0 | 이미지 설명 + **LLM 답변** |

**임베딩 모델**: `paraphrase-multilingual-MiniLM-L12-v2`
- 다국어 지원 (한국어 포함)
- 벡터 차원: 384

**LLM 모델**: `claude-sonnet-4-20250514`
- 답변 생성용

## 10. 결론

PDF 문서를 벡터 데이터베이스로 변환하여 자연어 검색이 가능한 RAG 시스템을 성공적으로 구축했습니다.

**v3.0 주요 성과**:
1. **LLM 답변 생성 통합**: 검색 결과를 Claude가 분석하여 자동 답변 생성
2. **전문가 수준 프롬프트**: 문서 기반 + 추론 기반 답변, 전문가 상담 권고
3. **자동 DB 구축**: `build_db.py`로 폴더 기반 일괄 처리
4. **대규모 DB**: 19개 PDF, 79,820개 청크
5. **GitHub 연동**: 버전 관리 및 협업 가능
